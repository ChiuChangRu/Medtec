# 台灣醫療器材商情查詢

以產品類別、製程能力及市場線索查詢歐噴資料庫公開索引的靜態網站。左側選擇主題，右側大幅顯示搜尋與結果。

## 資料來源

| 來源 | 用途 |
| --- | --- |
| [歐噴資料庫](https://data.openfun.tw/) 公開統一搜尋 API | 免登入檢索資料集及條目摘要；逐筆 API 可能需授權 |

站內沒有預載商機數字。搜尋索引不等於銷售量、採購需求或合作意願；需回原始來源確認。

## 部署與本機預覽

儲存庫根目錄的 `index.html` 由 GitHub Actions 自動部署至 GitHub Pages。正式網址為 https://chiuchangru.github.io/Medtec/ 。本機預覽可執行 `python -m http.server 8000` 後開啟 `http://localhost:8000/`。

網站是純前端，無建置程序與伺服器端密鑰。公開索引查詢不需 Token；歐噴 API 的流量限制、服務狀態和瀏覽器跨來源政策可能影響查詢。

## 設計說明

以清晰的雙欄版面、較大的字體和資料卡片呈現查詢結果。
